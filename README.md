# The World Economy, Five Ways

One simple model of the world economy (US, China, EU, Japan, India, Gulf/OPEC+, emerging markets; oil, shipping chokepoints, chips, food, tariffs and trade deals, sanctions, central banks, the dollar, inflation, rates, debt, jobs, spending) and seven what-if scenarios, shown five ways in tabs: a living city map, a board game, plumbing and valves, a ripple pond, and a dashboard of dials. Each scenario plays step by step and ends with a Quick read of likely winners, losers, warning signs and rules of thumb.

Open `index.html` in a browser; it is a single self-contained file with no external dependencies. Hosted via GitHub Pages.

**Illustrative directional effects only. Not forecasts and not financial advice.**
