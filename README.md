# The World Economy Contraption

A single-page, Rube Goldberg-style simulation of the world economy at a 10,000-foot view. Pick a what-if (oil doubles, Taiwan chip disruption, sharp Fed cuts, US–China tariff hike, Strait of Hormuz closure, EU recession, weak dollar), pull the lever, and watch the effect ripple through oil, shipping, chips, trade rules, central banks, the dollar, inflation, jobs and spending. Click any part to see what it does and which rules make its path convoluted. Each scenario ends with a Quick read of likely winners, losers, warning signs and rules of thumb.

Open `index.html` in a browser; no build step or dependencies. Hosted via GitHub Pages.

**Illustrative directional effects only. Not forecasts and not financial advice.**
